# Assertions

`expectArc` wraps a Fastify `app.inject()` response and exposes fluent matchers for arc's response envelope. It replaces the 5-6 patterns that were repeated hundreds of times across the test suite — one call chain reads as a sentence.

## Basic usage

```typescript
import { expectArc } from '@classytic/arc/testing';

const res = await ctx.app.inject({ url: '/jobs/123', headers: admin.headers });

expectArc(res)
  .ok()                        // status 200, body parses as JSON
  .hasData()                   // body is non-empty
  .hidesField('password')      // body.password absent
  .showsField('title');        // body.title present
```

Every helper returns the assertion object, so everything chains. `expect` is called internally — import `expectArc` only from files that run under `vitest`.

## Status

| Helper | Checks |
|---|---|
| `ok(status = 200)` | status is exactly `status` AND the body parses as JSON |
| `hasStatus(status)` | status is exactly `status` (body not inspected) |
| `failed(status?)` | status >= 400 (or exactly `status`) AND `body.code` is set (the error contract) |
| `unauthorized()` | `.failed(401)` |
| `forbidden()` | `.failed(403)` |
| `notFound()` | `.failed(404)` |
| `validationError()` | `.failed(400)` |
| `conflict()` | `.failed(409)` |

```typescript
expectArc(res).ok();                    // 200
expectArc(res).ok(201);                 // 201 (POST create)
expectArc(res).unauthorized();          // 401 + error body
expectArc(res).forbidden();             // 403 + error body
expectArc(res).notFound();              // 404 + error body
```

## Data

```typescript
expectArc(res).hasData();                         // body is non-empty
expectArc(res).showsField('id');                  // body.id defined
expectArc(res).hidesField('password');            // body.password absent

// Raw access for ad-hoc assertions (a single document IS the body)
expect(expectArc(res).body).toMatchObject({ id: '123', title: 'x' });
```

## Pagination

A list response is the `OffsetPaginationResult` itself: `data`, `page`, `limit`, `total`, `pages`, `hasNext`, `hasPrev`.

```typescript
expectArc(res).paginated({
  page: 1,
  limit: 20,
  total: 42,
  hasNext: true,
  hasPrev: false,
});

// Without expected values — just asserts `data` is an array
expectArc(res).paginated();
```

Requires `body.data` to be an array, so a bare `{ data: [...] }` list passes too.

## Errors & meta

```typescript
expectArc(res).hasError('Permission denied');          // exact match
expectArc(res).hasError(/^Permission/);                // regex

// `meta` is flattened to top-level by sendControllerResponse, so
// both shapes are accepted:
expectArc(res).hasMeta('validActions', ['approve', 'reject']);
expectArc(res).hasMeta('traceId');                     // key present, any value
```

## Ad-hoc drill-down

```typescript
const a = expectArc(res);
a.ok();
console.log(a.body);                         // parsed body (cached)
console.log(a.data);                         // body.data — the array on a list response (cached)
console.log(a.response.statusCode);          // raw Fastify response
```

`.body` and `.data` memoize — repeated access doesn't re-parse.

## Failure messages

Every matcher includes context on mismatch so failures read as diagnostics, not "expected true to be false":

```
AssertionError: expected 2xx (200) but got 500. Body: {"code":"…","message":"DB unreachable","status":500}
AssertionError: expected field 'password' to be hidden from response
AssertionError: response body is not valid JSON (statusCode=200): Unexpected token '<' ...
```

## When NOT to use

- **Non-arc responses.** `failed()` needs the error contract's `code`; a route answered outside arc's error handler does not carry one. Use `hasStatus(404)` or check `response.body` directly.
- **Non-JSON bodies.** `expectArc` parses JSON eagerly on first body access. If you're testing a binary download or SSE stream, stick with raw Fastify response assertions.

## API

```typescript
interface ArcAssertion {
  readonly response: ArcResponseLike;
  readonly body: Record<string, unknown>;
  readonly data: unknown;

  ok(status?: number): ArcAssertion;
  failed(status?: number): ArcAssertion;
  unauthorized(): ArcAssertion;
  forbidden(): ArcAssertion;
  notFound(): ArcAssertion;
  validationError(): ArcAssertion;
  conflict(): ArcAssertion;
  hasStatus(status: number): ArcAssertion;
  hasData(): ArcAssertion;
  hidesField(field: string): ArcAssertion;
  showsField(field: string): ArcAssertion;
  paginated(expected?: {
    page?: number;
    limit?: number;
    total?: number;
    hasNext?: boolean;
    hasPrev?: boolean;
  }): ArcAssertion;
  hasError(matcher: string | RegExp): ArcAssertion;
  hasMeta(key: string, value?: unknown): ArcAssertion;
}

function expectArc(response: { statusCode: number; body: string }): ArcAssertion;
```
