# MCP — AI Agent Tools

Arc auto-generates [Model Context Protocol](https://modelcontextprotocol.io) tools from your resources, so AI agents (Claude, Cursor, Copilot) call your API through the same `BaseController` pipeline as REST — auth, org-scoping, hooks, field permissions, and cache all apply.

**Why it matters for integrations & plugin authors:** MCP is not a separate surface to maintain. Define a resource once; its tools, REST routes, and OpenAPI doc stay in lockstep. Custom tools (`defineTool`) and prompts (`definePrompt`) compose alongside the auto-generated ones, and tool-name collisions between presets and your own tools are detected with source attribution.
